## 4. Data Model, Domain Integrity & Recovery Safety (Constitution Principles III & IV)

- [x] **CHK010**: All 10 new physical tables (`trains`, `teams`, `members` without `team_id`, `member_team_assignments`, `pis`, `iterations`, `locations` with `seeded_years` & `library_seed_cutoff_date`, `holidays`, `absence_types`, `absences`) inherit F001's `auditColumns()`, use `ON DELETE RESTRICT` foreign keys (never `ON DELETE CASCADE`), enforce case-insensitive name/code uniqueness, separate `record_status` from `pis.lifecycle_status` (`F6`), and store calendar dates as timezone-independent ISO `YYYY-MM-DD` strings.
- [x] **CHK011**: Canonical ART `Iteration` identity/dates (Mon–Fri weekday boundaries, `OD-1`) remain strictly separate from derived `TeamIterationSchedule` boundaries (`shiftWorkdays` Mon–Fri `-1`/`0`/`+1`, guaranteeing zero shared shifted days), and `plan.md` introduces zero `PlanVersion`, `PICommitment`, `SprintCommitment`, or `Actuals` tables/events.
- [x] **CHK012**: Canonical date constraints (Mon–Fri Sprint start/end `400`, active-PI non-overlap within ART, cross-ART overlap allowed, Iteration non-overlap and containment within parent PI, gaps permitted, `YYWW` optional helper never overriding dates) and Today-widget Team-shifted matching + tie-break (`OD-2`) + Sprint prefix formatting (`OD-5`) are enforced in pure domain validators and transactional services.
- [x] **CHK013**: Soft-archive (`record_status: 'active' | 'archived'`) on ARTs, Teams, Members, PIs, and Locations (`OD-3`) never auto-archives children, blocks archiving a Team with pending incoming moves (`409`, `OD-8`), blocks new child assignments and child reactivation under archived parents (`409`, while allowing reactivation of a Member whose Location is archived), blocks assigning/moving Members to archived Locations or Teams (`409`), uses `member_team_assignments` as sole source of truth for date-resolved Team membership (`OD-8`, `OD-9` same-day/pending correction, `OD-11` no backdating `< today`, pending correction back to original Team collapses as cancel, move before pending returns `400` instructing cancel first), applies Absence conflict checks only to `affects_capacity = true` types (`OD-10`), and restricts hard deletion to unreferenced records only.
- [x] **CHK014**: Reference-data seeding (`src/persistence/seed.ts`) uses `holidays_library_identity_unique` (`(location_id, date, name) WHERE source = 'library'`, `F3`), immutable Location `code` (`R2-2`), explicit `seeded_years` + `library_seed_cutoff_date` preventing pre-cutoff seeding on restart or year rollover (`R2-1`), concrete Islamic/Hijri `confirmed = false` rule (`F5`), `company`/`manual` override precedence, conditional `last_refreshed_at` updates (`F4`), and injectable server-local `today` (`R2-3`), running inside F001's locked migration flow before `.azusa-last-healthy.json` is written.
