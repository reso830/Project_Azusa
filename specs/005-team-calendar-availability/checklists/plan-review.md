## Re-review notes (2026-11-29)

Verified the recorded R1 approval and legacy-data policy, shared trailing-weekend loader bounds and integration coverage, T006/T026 version assertions, and D6 approval with a populated milestone-header axe check.

- **MAJOR — CHK001, CHK003, CHK014. The revised holiday reconciliation compares different units.** R7 and T004/T010 equate the FTE-weighted sum of `devDaysLost` with F004's unweighted `holidayDaysRaw`. One full holiday for a 0.5 FTE Member yields 0.5 versus 1.0. Keep the same-date deduplication and compare the sum with the FTE-weighted eligible-member holiday total derived from F004. Assert 0.5 for the primary row and 0 for the secondary row in a mixed-FTE or part-time fixture without changing the existing F004 field.
- **MINOR — CHK003, CHK013, CHK014. Restore still has two possible outcomes for a missing stored row.** Spec R8 returns the missing-library warning when the original row no longer exists. The contract and T008 first try to regenerate the key. Define regeneration in R8 and test both the regenerable and no-longer-generated cases. Distinguish a library row being available from being effective when a same-date company/manual record still takes precedence.
- **MINOR — CHK012, CHK014. The absence PATCH guard matrix leaves a request shape uncovered.** The strict body allows `{ status: "cancelled", date: ... }`, but the guard matrix covers only an active result or cancel-only. A date change while already cancelled also falls through. Specify whether those requests are rejected or validated as edits, and assert that the historical cancel-only exception cannot move or reclassify an absence.
- **MINOR — CHK001, CHK005, CHK014. Compact-mode duration needs a separate definition from ISO week bands.** T002 exposes `weeksCount` and uses it to select compact mode without defining its basis. A three-week Tue–Mon or Fri–Thu Sprint touches four ISO weeks. Define the duration-based compact trigger separately from the CW header count, and test a shifted three-week Sprint with four CW bands and normal-width columns.
- **INFO.** R6's prose says to replace prototype `#D00000` with `#D00000`. D6 and the handoff correctly identify `#FF0000` as the original.
